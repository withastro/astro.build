## Latest releases

Minor releases introduce new features and improvements. Check out what's new!

- [Astro 7.3](/blog/astro-730) - run multiple preview servers at once, a runtime logger for custom image services and cache providers, and a `finalize()` helper for Cloudflare custom worker entrypoints.
- [Starlight 0.42](/blog/starlight-042) - performance and accessibility improvements, less JavaScript, and more JavaScript, all in one release!

See some of the latest community-built [utilities and integrations](/integrations/) to help you build with Astro. 🛠

- [@astroscope/react](https://github.com/entwico/astroscope/tree/main/packages/react#readme): React for Astro islands, tuned for the server.
- [@clearfelt-slide/core](https://github.com/andrei-ionut-nita/clearfelt-slide#readme): An Astro-based slide-deck editor. Author, edit, and present straight from the same app.
- [@deltaq.dev/mines](https://github.com/deltaqdev/mines): A minimal Astro docs integration.
- [@dmthepm/commune](https://github.com/dmthepm/commune-wiki#readme): Maintain a personal wiki from Markdown notes with authoring tools, a shared link graph, and portable Astro publishing.
- [@igorskyflyer/astro-saferesource](https://github.com/igorskyflyer/npm-astro-saferesource): An Astro integration that adds CSP-compliant inline scripts and styles to your website.
- [@qymera/effects](https://www.npmjs.com/package/@qymera/effects): Free, tiny, native-first motion primitives for Astro, driven entirely by `data-q-*` attributes.
- [@sudodevstudio/astro-ai](https://github.com/SudoDevStudio/astro-ai#readme): Development-only Build with AI tooling for Astro projects.
- [@tcitry/astro-book](https://tcitry.github.io/astro-book/): A customizable static reading theme for Astro, inspired by Hugo Book.
- [@typed/astro](https://github.com/TylorS/typed-smol/tree/main/packages/astro#readme): Astro integration for Typed HTML templates and hydrated islands.
- [astro-cards](https://github.com/abemedia/astro-cards#readme): Generate Open Graph images from Astro components, at build time or on demand.
- [astro-feedback](https://www.npmjs.com/package/astro-feedback): Lightweight Astro integration for collecting design/dev feedback on pages, separated by viewport. Dev and staging only.
- [astro-feedback-board](https://github.com/SlashGordon/astro-feedback-board#readme): Anonymous, moderated feedback for Astro sites: a feedback button, inline question cards and a public board, backed by a Cloudflare Worker.
- [astro-flag](https://pascal-brand38.github.io/astro-dev/packages/astro-flag/): Add a responsive country flag in Astro, as an inlined SVG.
- [astro-iconify-component](https://github.com/Avaray/astro-iconify-component#readme): Inline SVG icons for Astro. Fully typed, accessible by default, Tailwind-friendly.
- [astro-if](https://gitlab.com/net.christianto/deps/astro-if#readme): Declarative conditional rendering components for Astro (If / Then / Else / When / Unless / Switch / Case). Shamelessly plagiarised from react-if, for those who hate ternaries.
- [astro-image-zoom](https://github.com/antoniohg/astro-image-zoom): Medium-style image zoom for Astro: accessible, animated from the page, with swipeable galleries.
- [astro-pkg-stats](https://github.com/MrGKanev/astro-pkg-stats#readme): Astro component and helpers that show npm and Packagist (Composer/Laravel) download statistics for your packages.
- [astro-refs](https://www.npmjs.com/package/astro-refs): Sphinx-style named refs for Astro: declare anchors anywhere, link by name, stay valid when content moves
- [astro-tweet-card](https://www.npmjs.com/package/astro-tweet-card): Astro component to render tweet cards.
- [astro-xitter](https://github.com/Namchee/astro-xitter#readme): Embed Xitter Post in Your Astro site.
- [daisy-astro](https://github.com/ok-98/daisy-astro#readme): Astro components for every daisyUI 5 component, where each daisyUI variant is a typed prop and every native HTML attribute is forwarded.
- [remark-myanmar-reading-time](https://github.com/kalixlouiis/remark-myanmar-reading-time#readme): Accurate reading time calculator for Myanmar (Burmese) script and mixed-language content in Astro, Next.js, and Remark.


### SEO/AEO

- [brixon-seo](https://www.npmjs.com/package/brixon-seo): SEO and GEO validation for Astro builds. Audits rendered HTML, native Astro redirects, sitemaps, robots access and structured data; includes configuration instructions for AI coding agents.

### CMS/text editors

- [emdash-plugin-linguadash](https://linguadash.dev): Translate EmDash content and SEO fields with DeepL, OpenAI or Cloudflare AI, and see which entries are missing, outdated or need review.
- [@plinto/astro](https://github.com/maxmart/plinto#readme): Plinto is an admin UI for Astro MDX sites, bundled into the deployed site itself: git-backed content, a visual block editor, and surgical AI translations driven by vector clocks.
- [astro-dev-edit](https://github.com/janjcwebtech/astro-dev-edit#readme): In-browser visual content editing for the Astro dev server — click text or images in the rendered page, writes straight to source. Dev-only.

### Markdown, Text, and more

- [astro-better-details](https://www.npmjs.com/package/astro-better-details): Expandable details/disclosure component for Astro.
- [astro-better-tables](https://www.npmjs.com/package/astro-better-tables): RST-style list-table and grid-table components for Astro.
- [astro-hidden-prompt](https://www.npmjs.com/package/astro-hidden-prompt): Invisible clipboard-copyable text for Astro MDX — guide LLMs when students paste assignment requirements.

### Content loaders

- [astro-textile](https://github.com/r8/astro-textile#readme): Textile integration for Astro. Provides a content loader that renders `.textile` files for Astro content collections.

### Dev toolbar apps

- [@caracode/pins](https://github.com/CaraCodeDev/caracode-pins/tree/main/packages/pins#readme): Astro dev-toolbar app for pinning notes onto page elements in local dev, stored as JSON for Claude Code to act on.
- [@opacedev/astro-ai-content-checker](https://github.com/OpaceDigitalAgency/opace-ai-content-checker-detector/blob/main/packages/astro/README.md): Free AI content checker and free AI content detector for Astro Dev Toolbar, with on-device section evidence, passage highlights, reports and model-free build checks.

### Starlight

- [i-cant-believe-its-not-vitepress](https://github.com/KTibow/i-cant-believe-its-not-vitepress#readme): A Starlight theme that looks and lays out like VitePress: sidebar, content and table of contents kept together in one centred column.
- [starlight-group-pages](https://starlight-group-pages.netlify.app): Starlight plugin to give your sidebar groups their own pages.
- [starlight-file-explorer](https://github.com/HiDeoo/starlight-file-explorer): Explore and document files and folders in your Starlight site with an interactive file explorer.

### Astro integrations by and for other tools

- [@casoon/astro-castwright](https://github.com/casoon/castwright#readme): Astro integration for castwright — `<TerminalDemo />` and automatic Vite plugin registration.
- [@ciphera-net/pulse-astro](https://github.com/ciphera-net/pulse-astro): Add Pulse Analytics — privacy-first web analytics — to an Astro site with one integration. No cookies, no personal data, under 3 KB.
- [@lilac-wysiwyg/astro](https://maifeeulasad.github.io/lilac/astro.html): Astro adapter for Lilac WYSIWYG editor - a client mount helper and an Astro integration
- [@micrajs/astro](https://github.com/denisfl/micrajs-astro#readme): Astro integration for Micra.js — per-island, per-component lazy hydration for HTML-first components.
- [@quantajs/astro](https://github.com/quanta-js/quanta/tree/master/packages/astro): Astro integration for QuantaJS: one store shared by React, Vue and Svelte islands, a container per request, and server state that reaches the islands.
- [astro-ai-chatbot](https://asyntai.com/documentation/integrations/astro/): Add the Asyntai AI chat assistant to your Astro site. It answers visitor questions from your own content, in 80+ languages.
- [astro-surreal](https://github.com/chrissxMedia/astro-surreal#readme): Run a bundled Surreal script once for each rendered instance of an Astro component.
- [astro-deploy-stack](https://github.com/anton-codes-iac/astro-deploy-stack#readme): Deploy-stack integration for Astro. Instantly generate zero-lock-in AWS ECS Fargate infrastructure for your Astro website.
