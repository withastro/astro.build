## Tips & Tools

See some of the latest community-built [utilities and integrations](/integrations/) to help you build with Astro. 🛠

- [@dennismiranda/astro-cart](https://github.com/DennisMiranda/cart-npm#readme): Functional e-commerce cart for Astro: side drawer, floating trigger, product variants, persistence, and theming via CSS variables.
- [@destination/astro-purge-css](https://github.com/wearedestination/astro-purge-css#readme): Astro integration that removes unused CSS from a static build and inlines small stylesheets.
- [@halfgray/astro-plugin-classic-js](https://github.com/jack126guy/astro-plugin-classic-js#readme): This Astro plugin enables imports of "classic" (non-module) scripts as static assets, with minification.
- [@rgglez/music-laserharp](https://github.com/rgglez/music-laserharp#readme): Playable laser harp Web Component (Three.js + Tone.js) with Astro, React, and Svelte wrappers and `gettext` translations.
- [@sjohansson/astro-votes](https://www.npmjs.com/package/@sjohansson/astro-votes): Like and dislike buttons for static Astro sites. Votes go to your analytics tool as events, a CI job writes the totals to a JSON file, and the site shows them at build time. No database.
- [@sudodevstudio/astro-dom-stamp](https://github.com/SudoDevStudio/astro-dom-stamp#readme): Stamp `data-*` attributes onto DOM elements rendered from fetched data.
- [astro-comments](https://www.npmjs.com/package/astro-comments): Plug-and-play, self-hosted comments for Astro: any server, any storage, works without JavaScript. In development.
- [astro-smart-links](https://astro-smart-links.vercel.app/): An Astro integration that adds smart styling and broken-link detection to internal and external links.
- [astro-strict-csp](https://github.com/Evgenii-Zinner/astro-strict-csp#readme): Zero-dependency Astro integration for strict Content Security Policy (zero 'unsafe-inline'), inline style and script extraction, bundling, Subresource Integrity (SRI) hashing, and CSP enforcement.
- [env-parity-plugin](https://github.com/acus9345/env-parity-plugin#readme): Fail your Astro build or dev server when a variable from `.env.example` is missing or empty, or when your code reads one the example doesn't list.
- [sri-sentinel](https://mrlouiswright.github.io/sri-sentinel/): Subresource Integrity (SRI) generator and checker.



### SEO/AEO
